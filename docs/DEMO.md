# 即時 demo 頁面說明

網址：https://alexlin8888.github.io/nsysu-youbike-log/

## 頁面怎麼讀

左欄有兩個分頁：「找車」給下課要借車的人看，「調度」給派卡車的人看；兩邊共用上方的倒數與右邊的地圖。

- **右上角狀態**：綠點 = 即時資料；橘點 = 重播；黃點 = 資料超過 25 分鐘沒更新。
- **倒數與時間軸**：距下一次鐘響幾分鐘；時間軸上粗線是 12、16、17 點三個大鐘響，藍點是現在。

### 找車（預設）

- **建議去**：從起點出發，最近而且不太會沒車的站（現在 ≥ 2 台、30 分內缺車機率 < 50%、下課後預估 ≥ 2 台）。起點預設是中山校園，可改用「用我的位置」或「點地圖選起點」。
- **我的站**：打開站點卡片按 ☆ 加入，只存在這台裝置的瀏覽器裡；地圖上的站會多一顆 ★。
- **附近的站**：依步行時間排序（直線距離 × 1.25、每分鐘 80 公尺）。每站一個白話標籤——有車／可能變少／可能沒車／很可能沒車／現在沒車，依 30 分內缺車機率分級（< 25%、25–50%、50–75%、≥ 75%）；空位 0 時另標「沒位子還車」。後面是「{下課後 20 分} 約 N 台」，由生滅鏈從現在的車數推算。
- **搜尋**：站名、英文名或校內簡稱（圖資、體育館…）都可以。
- **站點卡片**：車數、空位、30 分沒車機率、下課後 20 分的預計剩餘台數與沒車／沒位子的機率、今天 06:00 起的車數走勢（虛線 = 鐘響）、Google Maps 步行導航。

### 調度

- **四個數字**：目前空站數；30 分內缺車機率 ≥ 50% 的站數；未來 90 分全區預期借不到車的人次；建議路線能避免的人次與比例。
- **卡車路線**：每站標「載走 n 台」或「送 n 台」、預計幾分鐘後到、車上剩幾台。「複製路線」會把路線複製成文字，可貼給調度員。
- **缺車風險最高的站**：可切 30 分／60 分機率或「90 分缺口」（預期借不到車的人次），地圖顏色跟著切換。

### 地圖與重播

- **地圖記號**：外圈弧長 = 車柱裡有車的比例；內圈顏色 = 缺車機率（或 90 分缺口）；大小 = 車柱數；藍框 = 校內 8 站；灰色虛線 = 暫停服務或無資料。放大到校園會顯示站名。
- **重播**：右上角切「重播」並選日期，可拉時間軸或按播放看整天的變化；最近 7 個完整日會自動保留。兩個分頁在重播裡都能用。

## 影片建議（11/26）

拍攝時段建議選上課日的 15:30–17:30，那時校內站正在被借空，建議路線最清楚；或直接用重播模式選一個上課日。

1. 開場：即時頁面「找車」分頁，指出倒數與「建議去」，說明「每 10 分鐘更新，紀錄器在 GitHub Actions 上自動跑」。
2. 點體育館站：卡片的走勢圖看得到 12 點、16 點下課後兩次下跌，這就是題目的「鐘響」；念出「下課後 20 分預計剩幾台」。
3. 切到「調度」分頁，再切「90 分缺口」：顏色最深的是未來 90 分最缺車的站，解釋這是用生滅鏈算出來的預期人次。
4. 回到卡車路線：念一遍載走、送到、幾分鐘到，指出避免的人次與比例；按「複製路線」示範交給調度員。
5. 切到重播，選一個上課日，從 15:00 播到 17:30，讓觀眾看校內站變紅、路線跟著改。
6. 收尾：「方法與數據」摺疊區的三個數字（AUC 0.93、臺大重播 1/3/6 台車少 13/30/45%）。

## 資料從哪裡來

`state.json` 由 `analysis/code/demo_state.py` 在每次紀錄器快照後重算；`replay_*.json` 由 `analysis/code/demo_replays.py` 每天補齊。兩者都在 `.github/workflows/logger.yml` 的迴圈裡執行。
