## 工作一：旁白（約一小時）

要有新聞主播的感覺：口齒流利、咬字清楚，不能大舌頭。稿子在這份文件後面的「旁白稿」，分成 7 段，一段錄成一個檔，檔名 1 到 7；也可以全部錄在同一個檔，段和段之間停兩秒。每句念完停一秒，念錯就把那一段整段重錄。速度和影片字幕一樣，大約每秒 4 個字，先開著影片 `beat_the_bell.mp4` 跟字幕念一遍再正式錄。每段標題寫著大約幾秒，錄完看一下錄音長度，多出兩成以上就念快一點重錄。用手機在安靜的房間錄，嘴巴離手機約 20 公分。

## 工作二：實拍與現場核對（每個傍晚一個半小時）

課程鼓勵在影片裡展示系統實際運作，報告也缺一筆在現場核對的資料。這個傍晚要拍幾段實景，讓影片裡出現真的站和真的手機畫面，同時記下網站顯示的車數和現場實際的車數；報告會把記錄寫成一段「作者的現場核對」，註明是組員自己做的，不是使用者測試。

1. 16:30 打開網站（alexlin8888.github.io/nsysu-youbike-log）的「政策」分頁，用手機內建的螢幕錄影錄 10 秒，畫面要有地圖上的「+1小時」標記。
2. 17:00 到 17:50 站在圖資大樓站旁邊，每 10 分鐘記一次：網站上這一站顯示幾台車、網站寫的資料時間、站上實際停了幾台、其中幾台看起來不能借（倒在地上、明顯壞掉）。
3. 17:05 左右照「借車」分頁走一次：從系館或教室打開網站，選出發地，走到它建議的站，記下建議哪一站、從打開網站到走到站花了幾分鐘、走到時有沒有車。不一定要真的借車。
4. 拍攝：手機橫拍、1080p、每段 5 到 10 秒、拿穩。拍三種畫面：站的遠景，最好拍到 17:30 之後空掉的樣子；手拿著手機顯示網站、後面是同一個站；手機螢幕錄影操作網站一次。不要拍到看得出是誰的臉（從背後拍或只拍車架），不要邊騎車邊操作手機。

記錄表每次一列，可以用手機備忘錄照這個格式打：

| 日期 | 時間 | 站 | 網站顯示幾台 | 網站資料時間 | 現場實際幾台 | 看起來不能借幾台 | 備註 |
|---|---|---|---|---|---|---|---|
| 11/23 | 17:00 | 圖資大樓 | | | | | |
| 11/23 | 17:10 | 圖資大樓 | | | | | |

照網站走的那一次另外記：日期、出發地點、建議的站、花了幾分鐘、走到時有沒有車。拍到的畫面會剪 3 到 5 秒進影片，標明「實拍」和日期。

## 最後一步：上傳 YouTube、放連結、繳交（實拍的人負責）

1. 上傳 `beat_the_bell_voice.mp4`（字幕已經燒在畫面上）。瀏覽權限設「公開」或「不公開」，不要設「私人」，否則助教看不到。標題和說明照下面貼上。
2. 處理完用無痕視窗打開連結，確認看得到、長度在 4:00 以內。
