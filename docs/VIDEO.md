# 期末影片

課程規定：影片 4 分鐘以內並上傳 YouTube，超過就不算成績。要先講清楚為什麼做這個題目，再講方法和結果，鼓勵展示系統實際運作。PDF 報告第一頁標題下方、作者上方要放 YouTube 連結。

影片長 3 分 38 秒，是一支動畫，主角是虛構的中山大學資管系學生阿哲。畫面、字幕、音樂和音效都已經做好，只缺真人旁白。前一分半鐘講為什麼要做：傍晚下課借不到車，我們的紀錄顯示校內站常常一起空掉，現行友愛接力給得太晚，大家也坐得太久。接著是提案，預測型友愛接力，獎勵改送 30 分鐘騎乘時數。後半講方法和國外的做法，展示網站，最後是檢驗結果和建議書。

## 檔案

影片的原始檔在 `video/`，輸出在 `video/out/`（太大，不放進 git，重跑 `render.py` 就會產生）。

| 檔案 | 用途 |
|---|---|
| `video/out/beat_the_bell.mp4` | 字幕燒在畫面上，有音樂和音效，還沒有旁白 |
| `video/out/beat_the_bell_clean.mp4` | 同上但沒有字幕，上傳 YouTube 時另外附 `subtitles.srt` |
| `video/build/NARRATION.md` | 旁白稿，每一句的編號、出現和消失的時間、數字的念法 |
| `video/build/subtitles.srt` | YouTube 字幕檔 |
| `video/build/music.wav`、`sfx.wav` | 音樂和音效分軌，混音時用 |

## 錄旁白

1. 照 `NARRATION.md` 一句一句錄，每句存成一個檔，檔名用句子前面的編號（`01.wav` 到 `41.wav`，m4a 或 mp3 也可以）。句子前後留一點空白沒關係，程式會切掉。
2. 速度照字幕走，大約每秒 3.8 個字，比平常說話慢一點。數字照括號裡的念法，例如 309 念「三百零九」、91% 念「百分之九十一」。
3. 用手機錄就可以，找安靜的房間，嘴巴離手機約 20 公分，不要對著麥克風吹氣。
4. 錄完執行 `python video/mix_voice.py 錄音資料夾`。每一句會放到它字幕出現的時間；比字幕長的句子會自動加快，最多快 12%，再長就會列出來，那幾句重錄快一點就好。音樂在旁白時會再壓低，最後整體音量調到 YouTube 的 -14 LUFS。
5. 輸出是 `video/out/beat_the_bell_voice.mp4`（有字幕）和 `beat_the_bell_voice_clean.mp4`。

也可以整段一次錄完，只要跟著影片的字幕念、跟影片對齊，執行 `python video/mix_voice.py 整段旁白.wav`。

## 重新產生

畫面裡的數字全部來自網站和報告的資料，改了資料或旁白就重跑：

```
cd video
python -m http.server 8771 --bind 127.0.0.1 &   # render.py、audio.py、preview.py 用這個讀畫面
python data.py      # 從 docs/replay_2026-11-11.json 和 analysis/results/final/ 取數字
python script.py    # 旁白時間軸、字幕、旁白稿
python audio.py     # 音樂和音效
python render.py    # 每一場各一個 mp4，接起來、配上聲音、燒字幕
python preview.py /tmp/frames data@12 demo@29   # 只看某幾格，不必整支重算
```

旁白的句子和停頓寫在 `script.py`，畫面在 `engine/scenes.js`，每一場的動畫都對齊它那幾句旁白開始的時間，所以改旁白之後畫面會跟著移動。網站截圖由 `shots.py` 產生（11 月 11 日的重播）。

## 素材和版權

動畫、音樂和音效都是本組用程式畫出、合成的（`engine/`、`audio.py`），沒有用到別人的圖、音樂或商標。網站截圖是我們自己的網站，地圖底圖來自 OpenStreetMap，片尾有註明。字型是 Noto Sans CJK（SIL Open Font License）。阿哲是虛構角色，片中標明。

## 交出去之前

1. 影片長度在 3 分 50 秒以內（現在 3 分 38 秒），上傳後再看一次 YouTube 顯示的長度。
2. YouTube 設成「公開」或「不公開」（有連結就能看），不要設成「私人」。上傳 `_clean` 版時，在 YouTube 字幕選項上傳 `subtitles.srt`；上傳有字幕的版本就不用。
3. 把連結貼進 `report/video_url.txt`，重跑 `node build_final.js`，或直接在 Word 裡把第一頁的「link to be added after upload」換成連結，再轉成 PDF。
4. 旁白和畫面的數字和報告、網站一致：309 站、40%、56%、28%、69%、3%、近五成與 150 分鐘、40 分鐘、50%、30 分鐘、海資館 68%、體育館 61%、材料 59%、少 11%、每天多 25 趟、34 小時、少 27%、12 個測試日、91%、62%、四週。
