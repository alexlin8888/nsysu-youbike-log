# 期末影片

課程規定（HW5）：影片 4 分鐘以內並上傳 YouTube，超過 4 分鐘的部分助教不看。內容是整個期末專題的介紹、方法和最後結果，可以用投影片講，更鼓勵展示實際的系統畫面或運作過程。報告 `HW5_54.pdf` 最上方、標題之下、作者之上要附 YouTube 連結，11/26 23:59 截止。繳交前的分工在 [HW5_TASKS.md](HW5_TASKS.md)。

影片長 3 分 54 秒，是一支動畫，主角是虛構的中山大學資管系學生阿哲。畫面、字幕、音樂和音效都已經做好，只缺真人旁白。旁白用平常說話的方式，照「問題、原因、現在的獎勵、我們的做法、怎麼用、改善多少」的順序走，畫面左上角標著目前講到哪一段。前一分半鐘講為什麼要做：傍晚校內的站一半以上的時間沒車，原因是下課鐘一響車就被借光；高雄的友愛接力（從滿站借車或還車到空站，送 5 元騎乘券）要等站空了才給，對學校太晚。後半講我們的做法（預測哪一站快被借光，那一站現在還車就有獎勵，獎勵改成一小時免費騎乘），先在手機上播放網站的重播，再一步一步示範網站怎麼用，最後是改善多少：光靠獎勵每天傍晚少 23 人次借不到車，再加上下課前補車少 56 人次（−27%）。

## 檔案

影片的原始檔在 `video/`，輸出在 `video/out/`（太大，不放進 git，重跑 `render.py` 就會產生）。

| 檔案 | 用途 |
|---|---|
| `video/out/beat_the_bell.mp4` | 字幕燒在畫面上，有音樂和音效，還沒有旁白 |
| `video/out/beat_the_bell_clean.mp4` | 同上但沒有字幕，上傳 YouTube 時另外附 `subtitles.srt` |
| `video/build/NARRATION.md` | 旁白稿，每一句的編號、出現和消失的時間、數字的念法 |
| `video/build/subtitles.srt` | YouTube 字幕檔 |
| `video/build/music.wav`、`sfx.wav` | 音樂和音效分軌，混音時用 |

## 錄旁白

1. 照 `NARRATION.md` 錄 7 個檔，一段一個檔，檔名 1 到 7（m4a、mp3、wav 都可以）。每句念完停一秒，段落前後留一點空白沒關係。也可以 7 段全部錄在同一個檔，段和段之間停兩秒。
2. 語氣像新聞主播：咬字清楚、速度平穩、語氣肯定，句尾不拖音、不上揚，捲舌音和平舌音分清楚。速度和字幕一樣，大約每秒 4 個字。數字照括號裡的念法，例如 309 念「三百零九」、91% 念「百分之九十一」、「+1小時」念「加一小時」。
3. 每段標題寫著大約幾秒。錄完看錄音長度，多出兩成以上就念快一點重錄。
4. 用手機錄就可以，找安靜的房間，嘴巴離手機約 20 公分，不要對著麥克風吹氣。
5. 收到檔案後執行 `python video/mix_voice.py 錄音資料夾`（只有一個檔就直接給檔案）。程式在句子之間的停頓把每段切成一句一句：切點選停得久、而且切出來的長度和稿子比例相符的地方，所以句子中間短暫的停頓不會被切開。每句放到它字幕出現的時間，比字幕長的句子自動加快，最多快 15%，再長就列出來。旁白時音樂壓低 8 dB、音效壓低 4 dB，整體音量調到 YouTube 的 -14 LUFS。每句切出來的長度寫在 `video/out/voice_split.txt`。
6. 輸出是 `video/out/beat_the_bell_voice.mp4`（有字幕）和 `beat_the_bell_voice_clean.mp4`。

一句一個檔（`01` 到 `25`）也還能用；已經跟影片對齊的整段錄音，加上 `--aligned`。

## 重新產生

畫面裡的數字全部來自網站和報告的資料，改了資料或旁白就重跑：

```
cd video
python -m http.server 8771 --bind 127.0.0.1 &   # render.py、audio.py、preview.py 用這個讀畫面
python data.py      # 從 docs/replay_2026-11-11.json 和 analysis/results/final/ 取數字
python script.py    # 旁白時間軸、字幕、旁白稿
python audio.py     # 音樂和音效
python render.py    # 每一場各一個 mp4，接起來、配上聲音、燒字幕
python preview.py /tmp/frames relay@20 demo@23   # 只看某幾格，不必整支重算
```

旁白的句子和停頓寫在 `script.py`，畫面在 `engine/scenes.js`。每一句旁白再依全形空格分成幾個短句，動畫對齊短句開始的時間（例如講到「一台車都沒有」時跳出「0 台」），所以改旁白之後畫面會跟著移動。網站截圖由 `shots.py` 產生（11 月 11 日的重播）。

## YouTube

上傳 `beat_the_bell_voice.mp4`（字幕已燒在畫面上），瀏覽權限設「公開」或「不公開」。標題、說明和章節寫在 [HW5_TASKS.md](HW5_TASKS.md) 的「最後一步」，直接貼上；說明裡的時間會自動變成章節。上傳後用無痕視窗打開連結，確認看得到、長度在 4:00 以內。

## 素材和版權

動畫、音樂和音效都是本組用程式畫出、合成的（`engine/`、`audio.py`），沒有用到別人的圖、音樂或商標。網站截圖是我們自己的網站，地圖底圖來自 OpenStreetMap，片尾有註明。字型是 Noto Sans CJK（SIL Open Font License）。阿哲是虛構角色，片中標明。
